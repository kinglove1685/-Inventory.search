# Stock77777

재고 검색 대시보드 (Streamlit)

## 로컬 실행
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포
1. GitHub에 이 저장소가 최신 상태로 푸시되어 있어야 합니다.
2. Streamlit Cloud에서 `New app`을 눌러 이 저장소를 선택합니다.
3. Main file path에 `app.py`를 입력합니다.
4. Deploy를 누릅니다.

## 데이터 파일
기본 엑셀 파일: `재고관련 프로그램제작.xlsx`
Streamlit에서 파일 업로드로 대체할 수도 있습니다.
