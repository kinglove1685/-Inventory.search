# 재고 검색 대시보드

## 실행

- 로컬 실행: `python -m streamlit run app.py`
- 오프라인 실행(Windows): `재고프로그램_오프라인실행.cmd`

## 화면 구성

- 사이드바 메뉴:
  - `검색 표시`
    - `통합 검색`
    - `OCR 검색`
  - `멸균넘버 기준표`
    - `멸균넘버기준표`
- 기본 시작 화면: `통합 검색`

## 통합 검색 레이아웃 고정값

- 상단 라인:
  - 좌측: `통합 검색`
  - 우측: `Toric+M/F`, `멸균필터(코드/조건)`
- 입력 라인:
  - `코드/품명`, `컬러(컬러코드)`, `톤수`, `파워`, `CYL`, `AXIS`, `ADD`, `분류`
- 멸균필터 폭 기준:
  - 코드 입력: `AXIS~ADD`(2칸) 폭 기준
  - 조건 선택: `분류`(1칸) 폭 기준

## 멸균필터 규칙

- 기준 컬럼: `재고장` 시트 `멸균No.` (LOTNO 미참조)
- 모드:
  - `고정`: 정확히 일치
  - `이상`: 기준 이상
  - `이하`: 기준 이하
- 기준표 시트: `멸균넘버 기준표`
  - 화면에서 기준표와 계산된 이전/이후 코드 표시

## 상태 유지

- 화면 이동(`통합 검색`/`OCR 검색`/`멸균넘버기준표`) 후에도 입력값 유지
- `st.session_state`의 `persist_*` 키를 통해 검색 상태를 보존
